# FIDELITIZ — site vitrine

Site public : https://fidelitiz.github.io/

Démonstration du tableau de bord : https://fidelitiz.github.io/fidelitiz-mobile-test/

## Publication

Le site est publié sur GitHub Pages. Le workflow [GitHub Pages](.github/workflows/pages.yml) reconstitue l’export statique conservé dans les fichiers fidelity-site.part-aa à fidelity-site.part-ae, vérifie les routes principales puis publie le résultat.

Chaque mise à jour des fichiers d’export ou du workflow déclenche une nouvelle publication via GitHub Actions.
